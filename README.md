# Power BI Executive PMO Dashboard for ERP Projects

An **Executive PMO Intelligence Dashboard** designed to monitor ERP project portfolios, assess project health, identify emerging risks, and support data-driven management decisions.

This project demonstrates how **Power BI, Power Query, DAX, data modeling, and AI-assisted synthetic data generation** can be combined to build a practical PMO analytics solution for ERP implementation environments.

The dashboard is designed around the needs of an executive PMO, providing visibility across multiple dimensions of project performance, including **project progress, schedule, risk, issues, customer status, stabilization, and operational health**. Instead of focusing only on historical reporting, the solution aims to provide early signals that can help managers identify potentially unstable projects before risks escalate.

## Key Features

* **Executive Project Portfolio Overview**
* Project health and stability monitoring
* Risk scoring and risk distribution analysis
* Schedule and progress monitoring
* Critical issue and ticket tracking
* Customer and project status analysis
* Identification of **Stable, Stabilizing, and Unstable projects**
* Early-warning indicators for emerging project risks
* Weekly project-state monitoring
* Drill-down analysis from portfolio level to individual projects
* Management-oriented KPIs and decision-support visuals

## Data & Analytics

The project uses a **star-schema-oriented data model** with project, customer, date, issue, meeting, and weekly project-state information.

**Power Query** is used for data cleaning, transformation, standardization, and preparation. **DAX** measures are developed to calculate executive KPIs, risk indicators, project stability metrics, latest project states, issue counts, and portfolio-level performance indicators.

Because real organizational PMO data is often confidential, the project uses **AI-assisted synthetic data generation** to simulate realistic ERP implementation scenarios while preserving the analytical structure required for PMO reporting and experimentation.

## Objective

The ultimate goal is to move from traditional **descriptive PMO reporting** toward **intelligent project monitoring and early risk detection**, creating a foundation for future integration with machine learning, predictive analytics, and potentially topological analysis of project-state dynamics.
